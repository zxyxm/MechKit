# MechKit（MechKit）

面向 SOLIDWORKS 2024 的插件，为「加工件 BOM / 明细汇总」这类日常工作服务：

- **BOM 预览/明细汇总**：窗口打开后自动汇总，可选择总装、子装配体或单个零件作为 BOM 范围，直接编辑**名称、材料、工艺**，按命名规则反推并重命名零件文件，也可导出 CSV。
- **任务面板**：显示当前文档的图号、材料，点一下即可复制；零件属性可直接编辑并写回。
- **批量导出**：自动补齐同目录同名的零件 / 装配体与工程图，模型导出 STP，工程图导出 PDF，保存到指定输出目录；也支持 DWG / DXF / IGES / STL。可保持目录结构，输出重名冲突会记录并阻止覆盖。
- **快捷导出**：“命令面板”右侧的“快捷导出”选项卡内选择共同输出文件夹，“导出 BOM（Excel）”和“导出 STP＋PDF”均使用该目录及两级筛选。先选加工件、标准件或自定义大类；加工件二级按工艺（CNC、钣金等），标准件二级按中间名（五金、电机等），其他大类二级按分类前缀。切换大类会清空二级条件；二级可用逗号输入多个值，精确匹配且不区分大小写。大类选“全部”时不限制二级。STP/PDF 始终递归处理当前打开的整个装配体，不受选中组件影响，按完整路径去重；默认所有零件导出 STP，有同目录同名 `.slddrw` 时导出全部图纸 PDF，可勾选“仅有工程图的零件”。默认覆盖已有 STP/PDF，取消勾选则保留并在结果中说明；同批不同源文件重名仍阻止覆盖。压缩组件和未保存为外部文件的零件跳过并记录日志，结果写入导出报告。BOM 使用现有汇总规则及数量，生成带时间戳的 Excel。

批量导出窗口默认展示当前打开装配体的组件层级，可逐项勾选；重复实例只导出一份文件。名称以“参考”开头的组件保留在树中，但不读取其下层组件。保持目录结构按源文件所在目录计算。

导出窗口支持“第二字段”筛选：按文件名第二段读取，兼容短横线和下划线。例如 `20260929-p6061-下测板` 的第二字段为 `p6061`，`淘宝-五金-接头` 为 `五金`。选择字段会自动勾选匹配文件；开始导出时也会限定该字段，`p6061` 与 `6061` 分开处理。右侧“输出目录”指定这一组的保存文件夹；切换字段和目录可分别导出不同组。“全部字段”取消限定，“无第二字段”收录没有第二段的文件。BOM 带入的文件仍限于原先勾选的范围，若要按字段处理整个 BOM，可先全选再进入导出窗口。

BOM 的“安装说明、备注、购买链接”三列支持双击原位输入或粘贴，按 Enter、Tab 或点击其他单元格提交时，自动写入同名的文档级自定义属性并保存文件，同一文件的其他 BOM 行同步更新。编辑保留单元格选区，点击行头高亮整行，不弹编辑或错误对话框；保存失败显示单元格错误标记及底部提示。Esc 先取消单元格输入，保留 BOM。购买链接支持 http/https，Ctrl＋单击打开网页；留空可清除属性值。启用“读取自定义属性”后刷新读回已保存内容，CSV 保留网址，Excel 包含可点击超链接。虚拟件或未保存文件需先保存为外部零件。

BOM 顶部“关键词”输入框实时筛选对应行，搜索名称、位置、材料、工艺、备注、购买链接等字段，不区分英文字母大小写。空格分隔多个关键词时须全部匹配，可与类型筛选叠加；清空搜索恢复显示，保留未保存的修改和导出勾选。搜索只处理已加载的 BOM 数据，不打开或重新读取 SW 文件。

BOM 顶部“导入 BOM…”支持 Excel 首个工作表及 CSV。先匹配零部件，再预览逐字段差异；可选择“更新选中字段”或“仅补充空白字段”。空值不删除，数量按匹配实例合计核对并保留模型统计值。购买链接列可保留网址或文字，如“淘宝”“代理”“暂时不做”。导入只回填预览，确认后点击“应用 BOM 修改”保存到零部件。

以“代理”开头命名的零件，购买链接为空时自动显示“代理”；读取到已有网址或其他非空属性时保留原值。预览及 CSV / Excel 导出均保留该文字标记，只有 http/https 网址显示为可点击链接。“代理”也可通过单元格编辑或 BOM 导入保存为购买链接属性；清空属性后，代理件刷新时仍会按名称自动填入“代理”。

零件名称或完整名称包含“弹簧”（兼容“唐璜”）时，BOM 自动在备注中补充“需要测试”。已有备注会保留，用分号追加提示；已有“需要测试”时不重复追加。BOM 导入回填后也会保留此提示，预览及 CSV / Excel 导出使用相同备注。

“淘宝加工”大类（兼容“淘宝追加工”名称前缀或分类）的零件，备注自动追加“需要买回来加工”。保留已有备注且不重复追加，可与弹簧的“需要测试”同时显示；BOM 导入、预览及导出均保留此提示。

BOM 表格下方固定显示当前筛选范围的统计，例如“标准件 30 种 / 200 件；加工件 82 种 / 151 件；外部图纸 10 种 / 26 件；合计：122 种 / 377 件。”操作状态提示不会覆盖统计。每类的种数按文件路径和配置去重，同一零件在多个装配位置出现仍计一种；没有文件路径的零件逐行计种，件数累加数量列。CSV / Excel 最后一行使用相同统计，Excel 汇总行合并显示；合并导出前后统计口径一致。

BOM 列标题右侧“▼”提供多选筛选：勾选该列要显示的类别或字段值，点击“确定”仅显示匹配行。支持全选、全不选、空白值与清除当前列筛选；多个列和关键词条件同时生效，生效的箭头显示为蓝色。点击“显示全部”清除类型、关键词及列筛选。列标题文字仍可点击排序，右键列标题也可打开筛选。

**公差助手**：菜单或 MechKit 选项卡点击“公差助手”。在工程图选中一个或多个尺寸，左键点击网格预设写入公差；右键可自定义 `上公差/下公差/备注`（如 `0.03/0/销钉`）、`±0.02`、`H7` 或 `h7`。输入 `0` 或留空只清空该预设格，“清除选中尺寸公差”按钮才移除尺寸公差。预设自动保存并随配置导出；备注只作预设标签。普通尺寸可直接应用，角度尺寸跳过。孔标注点击预设时自动读取参数；仅一个参数时直接应用，多个参数时弹出选择孔径或深度；普通尺寸前缀和后缀也提供独立预设页。修改后保存工程图。

孔标注通过 [SOLIDWORKS 孔标注变量 API](https://help.solidworks.com/2019/english/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IDisplayDimension~GetHoleCalloutVariables.html) 独立设置参数公差；前缀、后缀仅支持普通尺寸（[SetText API](https://help.solidworks.com/2019/English/api/sldworksapi/SOLIDWORKS.Interop.sldworks~SOLIDWORKS.Interop.sldworks.IDisplayDimension~SetText.html) 不支持孔标注）。
- **属性批量写入**：把同一组自定义属性写入整个文件夹的文档。
- **配置快速导出**：点击 CommandManager 的「导出配置」，直接在桌面生成 `MechKit-settings.ini`，便于换电脑迁移。

## 1. 明细汇总怎么用

点击 CommandManager 的「MechKit」选项卡 → **明细汇总**（或菜单「工具 → 明细汇总」）。

若只需要某个部件的 BOM：保持预览窗口打开，在 SOLIDWORKS 装配树或图形区选中
零件/子装配体，再点预览窗口里的「选择部件」。表格会重新统计该部件范围，
此时「导出部件 BOM」只导出当前表格；点「全部装配体」可恢复总装范围。

也可以点击「读取子装配体」，插件会递归读取当前总装下的部件装配体并显示在
「部件装配体」下拉框中。选择任意部件后会立即按该部件重新统计 BOM；嵌套部件
以“上级部件 > 下级部件”的形式显示，便于直接选择，无需先在装配树中定位。

明细汇总默认按设计树顺序排列，左侧设计树与右侧 BOM 共用行高和滚动。每个加工件、标准件、库存件、备件或外部图纸实例对应一行 BOM，中间用水平虚线连接；装配、组件及参考所在行在右侧留空，因此连线不会交叉。加工件使用浅绿底、标准件浅蓝底，装配和组件统一浅紫底，外部图纸浅黄底；设计树与 BOM 整行底色一致，缺加工图只将工程图单元格标红，参考件灰字无底色、不展开。点击展开符号可折叠或展开下层，点击节点可选中对应 BOM 行。

点击 BOM 列头可改用表格排序，点击“设计树排序”表头恢复默认排列。预览与导出 CSV 保留实例顺序；用于布局的空白行不参与统计或导出。折叠只影响显示，导出仍包含当前范围的全部 BOM 数据。“一键生成 BOM”按文件、配置与装配位置合并同一零件的数量。

装配和组件行即使右侧“位置”等 BOM 列为空，也可以双击左侧设计树的名称打开对应装配体模型；展开符号仍用于折叠/展开。BOM 预览保持在 SOLIDWORKS 主窗口上方，可直接点击 MechKit 菜单的命名按钮处理选中零件，预览不会被主窗口遮住。

BOM 预览提供「应出图未出图」「命名不规范」「显示全部」快捷按钮。缺图筛选沿用工程图单元格的红底规则，排除钣金免出图项；问题列表不受装配树折叠影响，切换筛选保留尚未应用的编辑。

「导出 BOM」旁新增「合并导出 BOM」，可选择 CSV 或含缩略图的 Excel。按当前筛选范围，将同一文件路径、同一配置的零件跨装配位置合并并累加数量；不同文件或配置不合并，无文件路径的零件单独保留。位置、安装说明、备注等字段去重拼接，预览中的逐行数据和未应用编辑保持不变。原「导出 BOM」继续逐行导出。

设计树按以下顺序识别（兼容 `-` 和 `_` 分隔）：

- **参考开头**：不识别，不读取下层，不进入 BOM；左侧保留节点。
- **指定外部图纸前缀**：在“设置 → 大类与前缀”或“命名规则 → 外部图纸”逐条填写，例如“外部图纸1：`BRC-`”；可添加、删除多条。按完整前缀匹配，`BRC-` 可识别 `BRC-支架`，不识别 `BRC001`，横线和下划线都会保留。整体进入 BOM，装配体不展开。参考件优先排除，指定外部图纸前缀优先于其它分类。
- **库存开头**：库存件，整体进入 BOM，装配体不展开。默认前缀 `库存` 可在同一设置页修改。
- **备件开头**：备件，整体进入 BOM，装配体不展开。默认前缀 `备件` 可在同一设置页修改。
- **淘宝、代理开头**：标准件，整体作为一项进入 BOM，不读取内部零件。
- **日期后紧接“装配”**：继续遍历下层，作为 BOM 装配位置，例如 `20261010-装配-机架`。
- **日期后紧接“组件”**：继续遍历下层；左侧保留分组，但不增加 BOM 的装配位置，例如 `20261010-组件-紧固件组`。
- **可选生产套数（一般不使用）**：装配/组件后可加 `xN`（正整数），例如 `20260921-装配x2-测试1` 表示做两套，下属 BOM 零件数量乘以 2；`组件x2` 同样适用。不写时为一套，嵌套套数逐层相乘，并累计实际装配实例数量。此规则适用于总装汇总及选中部件汇总；选中部件按其自身套数统计，不继承范围外的父装配套数。
- **日期开头且命名规则中的材料字段非空**：加工件，整体计入，不再展开内部零件，例如 `20261010-6061-安装板`。材料字段跟随命名规则的段顺序；空值或占位符不算材料。
- **未匹配命名规则**：标为“命名不规范”，设计树、中间连线区域和 BOM 整行红底；保留在 BOM 中，装配体不展开。外部图纸仅按设置中的指定前缀识别。

选择部件作为独立 BOM 范围时，也按同一规则判断选中节点；选择标准件总成只输出该总成，选择外部图纸节点整体输出，选择参考节点不输出明细。

1. 窗口打开后会自动预览当前装配体或零件的 BOM；也可点「刷新预览」。
2. 或选「文件夹」，批量汇总一批零件。
3. 双击黄色单元格可编辑名称、材料、工艺和备注；装配说明列为只读，由设置页选择的文件名分段或自定义属性读取。
4. 双击表格任意一行会打开该零件的图：优先同目录同名的工程图（`.slddrw`），该零件没有工程图时改为打开零件 / 装配体模型；已打开的文档会自动切换到它。单元格编辑用单击选中后直接输入或按 `F2`。
5. 点「按规则重命名文件」会从表格中的名称、材料、工艺反推文件名：加工件保留日期和尾部变更段，标准件按“工艺-名称-型号”组装；随后通过 SOLIDWORKS 重命名接口更新零件文件和当前装配引用。此操作不会写入自定义属性，备注不参与文件名。

表格最左侧是「导出」勾选列：勾选需要的行后点「导出选中件…」，插件会把勾选文件带进批量导出窗口，并自动补齐同目录同名的模型与工程图。默认勾选 PDF 和 STP，指定输出目录即可开始；缺少配套文件会在日志中提示，仍可导出已有文件。自动配对不搜索异名或其他目录的工程图。底部「全选」可以一次勾选当前表格里的所有行。

表格左上角（行头与列头交汇处）是「表头设置」入口：点一下直接打开「设置 → BOM 格式」，改表头名称、字段来源和列顺序，不用再从菜单绕。

「三维名称」列就是零件 / 装配体的文件名，可以直接改：**双击名字文字**进入编辑，提交后会问一次是否把文件重命名（走 SOLIDWORKS 的重命名接口，装配引用同步更新，不会断装配关系）；选择“否”就只保留表格里的名字，稍后点「按规则重命名文件」统一执行。

**双击名字后面的空白区域**（或其它列）会打开这一行的**三维模型**；三维文件打不开时才退回打开工程图。需要在表格里直接改名字、又不想动文件时，用「按规则重命名文件」按钮即可。

「二维工程图」列显示同目录同名的工程图文件名，并影响整行底色：

- **有二维工程图** → 整行浅绿；
- **加工件没有二维工程图** → 整行浅红（提醒补图）；
- 标准件 / 参考件没有工程图时不标色（标准件可以有追加工图纸，有图就会标绿）。

另外，在表格里选中一行（或多行）后，直接点 MechKit 选项卡上的快捷按钮（前缀 / 中间名 / 加工件材料…）就会作用于选中的这些零件，不必再回装配树里重新选一遍；关掉 BOM 窗口后按钮恢复成“用 SOLIDWORKS 里的选择”。

默认输出列：`序号 | 位置 | 完整名称 | 属性 | 零件名称/标准件名称 | 材料/型号 | 工艺/渠道 | 表面处理 | 数量 | 安装说明 | 备注`。“完整名称”保留未拆分的零部件名称（不含扩展名和装配实例序号）。所有表头都可在「设置 → BOM 格式」直接改名；通过底部“移动表头”选择列并点击“左移 / 右移”即可调整顺序。BOM 预览和 CSV 导出使用相同顺序、表头和内容。加工件的“表面处理”“安装说明”会自动寻找命名规则中的同名分段；未配置相应分段时留空。

「设置 → BOM 格式」中的字段下拉菜单优先跟随命名规则：加工件只显示当前实际存在的分段，并标出已勾选“并入 BOM”的段；标准件固定为三级“前缀-中间名-型号”，例如 `淘宝-按钮-S22`。第三级型号会整体保留，型号自身包含短横线时不会被拆成额外级别。开启“使用 SOLIDWORKS 属性表字段”后，下拉菜单末尾才会追加名称、材料、工艺、备注和装配说明等属性来源；关闭后仅按文件命名规则解析。

大类包括加工件、标准件、参考件、库存件、备件、外部图纸。库存件和备件在 BOM 属性列、数量统计、CSV 导出中分别显示；名称取前缀后的完整内容，材料、工艺等读取启用的自定义属性，不套用加工件日期分段或标准件型号字段。

CommandManager 增加“库存件”“备件”“外部图纸”：前两项给选中零件添加各自配置中的第一个前缀，外部图纸按钮打开前缀配置。命名规则页也提供这六类选项卡。

BOM 类型筛选提供“全部类型”“只看加工件”“只看标准件”“只看库存件”“只看备件”“只看外部图纸”。类型只按上述设计树命名规则判断，不再按 Toolbox 路径、厂商关键词或自定义“来源”属性推断。

## 2. 命名规则（重点）

### 2.1 图号

默认取**完整文件名（不含扩展名）**。图号来源 / 截断规则不再是界面上的常驻选项，设置值保留在配置里，需要切换时告诉我（或直接改 `%LOCALAPPDATA%\MechKit\settings.ini` 的 `PartNumberSource` / `PartNumberCutRule` / `PartNumberPattern`）：

| 选项 | 说明 |
| --- | --- |
| 文件名 | 直接用文件名 |
| 自定义属性优先 | 先读「图号 / 零件号 / 零件代号 / 代号 / PartNumber」，读不到再退回文件名 |
| 仅自定义属性 | 只认自定义属性 |

「文件名截断」还可以取第一个空格前 / 下划线前 / 短横线前，或自定义正则（正则捕获组 1 优先）。

### 2.2 名称与材料按段解析

新名称统一使用 `-` 分隔；读取和 BOM 识别同时兼容旧的 `_` 与 `-`：

```
20260908-6061-扫码枪安装板.sldprt
   ↓       ↓        ↓
 （日期） 材料=6061  名称=扫码枪安装板
```

- **时间段**固定为第 1 段，用来判定加工件，不能移动或删除
- 默认仅保留五段：**日期、材料/工艺、零件名称、版本号、安装说明**
- 版本号和安装说明默认并入 BOM 零件名称；其他**自定义段**仍可通过 `＋ 增加段` 添加
- 新增的**自定义段**可直接输入名称，例如“供应商”“表面处理”“项目号”，保存后会保留
- 除时间段外，可用 `↑ / ↓` 调整顺序，也可删除；材料和名称会按调整后的段位置解析
- 勾选某段右侧的“并入 BOM 名称”，该段会和零件名称一起显示在 BOM；例如勾选第 3～5 段后，`板1-A-左装` 会作为 BOM 零件名

只有文件名里真的分段时才会生效；`拨线板.sldprt` 这类名字会原样作为名称，材料留空。

加工件二级字段（材料）使用**一张合并表**维护，一行就是一条材料段配置：

| 列 | 作用 |
| --- | --- |
| 材料段（文件名取值） | 文件名里材料段实际写的字，例如 `6061`；留空时按“材料”列取值 |
| 材料 / 工艺 / 表面处理 | 这一行在 BOM 里对应的材料、工艺、表面处理；某一段留空表示该列不填 |
| 选项卡 | 勾选后该材料段**立即**显示在标准件快捷区上排（按钮顺序 = 表格行顺序） |

默认 `6061` 解析为 `6061 / cnc / 本色氧化`，`5052` 解析为 `5052 / 钣金 / 白色细砂纹烤漆`；`淘宝` 这类“材料留空、只写工艺”的映射把材料段填 `淘宝`、工艺填 `追加工` 即可。行尾 `×` 删除该行，底部「增加材料段」输入后点「＋ 增加」新增一行。保存后仍按 `材料段=材料|工艺|表面处理` 与材料段列表分别存储，旧配置会自动合并到同一张表里。

命名规则、BOM 表头设置和生成结果使用同一套字段语义：调整命名段顺序或自定义段名称后，BOM 设置中的加工件字段来源会按“名称 / 材料 / 版本号 / 安装说明”等含义自动跟随，不依赖固定第几段；表头名称、字段来源和左右顺序会直接用于 BOM 预览与 CSV 导出。

插件命令只显示在 SOLIDWORKS CommandManager 的 `MechKit` 选项卡中，不创建独立工具栏；选项卡布局会在正常退出后保留，并在切换文档时自动检查和恢复。

命名规则页可维护快捷字段：加工件二级字段（材料）在「材料段二级解析与快捷按钮」的一张表里维护，勾选“选项卡”的字段会出现在标准件快捷区上排；标准件一级字段为渠道/前缀，二级字段为中文名称，两排按钮“上一级在上、下一级在下”，不同级别不会混排。点击快捷按钮会按当前命名段顺序更新对应字段。

加工件三级字段（零件名称）的按钮配置仍保留在设置里（`MachinedLevel3Values` / `MachinedTabLevel3Values`），只是不再占用设置页界面。

保存命名规则时会立即重建 `MechKit` 选项卡上的快捷按钮：新增字段、勾选或取消勾选“选项卡”都会当场生效，不需要重启 SOLIDWORKS；任务面板上的前缀 / 中间名按钮也同步刷新。SOLIDWORKS 要求“命令按钮集合变化时换用新的命令组 UserID”，插件每次刷新都会用新 ID 重建命令组与选项卡，再删除旧命令组，因此不会出现旧按钮残留或整个 MechKit 标签消失。

所有独立窗口共用响应式窗口规则：根据当前屏幕工作区限制初始及最小尺寸，兼容字体/DPI 缩放，恢复上次位置时自动拉回可见区域；内容较长的设置页使用滚动区域，底部操作按钮保持独立。

### 2.3 模板占位符会被忽略

中文模板会把未填写的标题栏属性留成 `“图样名称”`、`“图样代号”`、`材质 <未指定>`，
这些值会被当作空，不会污染汇总结果。

### 2.4 标准件前缀

「标准件（前缀开头）」设置页只负责维护前缀：输入名称后点「增加」，或点击当前前缀上的 `×` 删除；前缀按空格分隔，例如 `电机 淘宝 气动`。
保存后的前缀与中间名会显示为 SOLIDWORKS MechKit 选项卡及任务面板上的快捷按钮；默认中间名包括接近开关、直线导轨、电机和丝杆，其中直线导轨默认绑定代理前缀。先选中零件，再点击按钮即可直接改名。

标准件一级字段、二级字段的每一行后面都可以写**备注**（例如给「传动」写上“直线导轨和直线模组和滚珠丝杆等”）。备注只用于记录、方便自己辨认，不参与命名和 BOM 判断，会随设置一起保存并包含在便携配置里。

“中间名 → 前缀绑定”规则本身仍在配置里生效（例如点“直线导轨”会自动带上“代理”前缀），只是不再占用设置页界面；想调整绑定关系时告诉我，或直接改 `%LOCALAPPDATA%\MechKit\settings.ini` 的 `StandardPrefixBindingEnabled` / `StandardPrefixBindings`。
快捷按钮现在通过 SOLIDWORKS 的文档重命名接口修改零件文件名，而不只是修改组件实例显示名。每次操作可选择直接修改原零件，或先使当前组件独立再修改；后者会在原目录新建一个零件文件，并只替换当前选中的实例。完成后会明确提示新建文件。
加工件快捷区另提供「时间」「6061-」「_→-」「撤回」和「装配」按钮：「时间」写入当天日期首段，已有合法日期前缀时更新为当天日期；「6061-」在合法日期首段后插入参考材料，例如 `20260919-安装板` 改为 `20260919-6061-安装板`，已存在时不会重复添加；「_→-」把选中零件或子装配体文件名中的全部下划线转换为短横线；「撤回」撤销最近一次 MechKit 快捷命名；「装配」给选中组件文件名增加 `装配-` 前缀，已有时不重复。
BOM 收录范围等通用选项统一在「个人配置」中设置，不在前缀页重复显示。

### 换电脑迁移 MechKit 配置

在「设置 → 个人配置」中点击「导出 MechKit 配置…」，会生成
`MechKit-settings.ini`。把该文件复制到另一台电脑的 MechKit 安装根目录
（与 `MechKit.dll` 同目录，默认 `C:\MechKit`），重启 SOLIDWORKS 后自动生效。

便携配置包含命名规则、标准件前缀/中间名、绑定规则、材料工艺预设和 BOM
字段映射；不会携带窗口位置、输出目录及 SOLIDWORKS 本机目录，避免换机后路径失效。

## 3. 安装 / 卸载

### 板件一键出图（离线）

孔标注按源特征去重：阵列、镜像、复制等复用同一源特征的孔，在整张图只保留一次标注，不因视图或加工面不同而重复。数量前缀完全使用 SOLIDWORKS 原生结果，不自行计算、修改或校验；独立创建的源孔特征分别保留。

激活零件或装配体，点击 **MechKit → 板件一键出图**（CommandManager 和菜单均可用）。单独打开零件时，为其当前活动配置生成工程图；激活装配体时扫描并批量生成。窗口显示进度、跳过/失败原因与待复核项，可停止；完成后双击结果打开工程图，或查看文本处理记录。未保存的零件或有未保存修改时会提示先保存。

- 递归扫描子装配体，同一路径和配置的重复实例只处理一次；不限 6061 材料。沿用 MechKit 命名规则排除参考件、标准/外购件、库存、备件和外部图纸。
- 根据实体的平行外侧大面及厚度识别单实体板件，不按文件名中的“板”判断。厚度须小于两个面内方向包络，且两个大面面积须大于侧面；这是保守的几何候选判断，不是加工工艺鉴定。钣金、多实体、没有可靠定向大面的形状会跳过。
- 使用内置 A3 第三角模板，保留技术要求和粗糙度。按实际面定向并将长边横置，建立关联投影视图、真实长宽厚尺寸及可识别的原生孔标注；侧孔按需要增加关联端面视图。
- 工程图保存到零件原目录，**同名 `.SLDDRW`**，不加日期或“工程图”后缀。不生成 PDF，不覆盖已有图，不保存源零件。先在同目录临时文件中保存、重开核对引用、配置、标注与技术要求，再发布同名文件。
- 同一文件被引用多个配置时会报告冲突并跳过，避免同名输出互相覆盖；活动配置与装配引用配置不同、源零件有未保存修改、虚拟零件或子装配未解析时也会明确提示。

孔向导通过定位草图核对加工入口；不把出口当作第二个沉孔入口。孔深超出实体厚度、未覆盖的孔入口、复杂槽/台阶及密集引线会列为 **已生成·待复核**。当前不自动推断任意槽的专用公差，也不补全孔位尺寸链、形位公差等未配置的工艺要求；此类输出应按结果记录复核后使用。

整个功能在本机通过 SolidWorks COM 执行，不需要大模型、网络、Python 或 Codex。模板已嵌入 DLL，运行时释放到 `%LOCALAPPDATA%\MechKit\drawing-templates`；处理记录在 `%LOCALAPPDATA%\MechKit\plate-drawing-reports`。

开发验证：`powershell -File tools\Test-PlateDrawing.ps1` 执行离线检查；加 `-Live -Parts <零件路径数组>` 可连接现有 SolidWorks，在 `artifacts\plate-drawing-tests` 的独立副本上检查实际生成、最终同名引用、重复实例去重、重复运行保护及取消。测试不覆盖输入零件或已有工程图。

### 安装做了什么（与嘉立创 Ican 工具箱同一套思路）

1. 把 `MechKit.dll` 和三个互操作程序集复制到 `C:\MechKit\`
   （和 Ican 一样：插件自带互操作程序集，不依赖宿主目录探测）。
2. 机器级注册 COM，布局与 `regasm /codebase`、`SolidWorksAddinInstaller.exe` 完全一致：

   ```
   HKLM\SOFTWARE\Classes\CLSID\{GUID}
     (Default)                      = MechKit.Addin
     \InprocServer32                = mscoree.dll, ThreadingModel=Both, Class, Assembly,
                                      RuntimeVersion=v4.0.30319, CodeBase
     \InprocServer32\0.1.0.0        = 同上（regasm 的版本子键）
     \ProgId                        = MechKit.Addin
     \Implemented Categories\{62C8FE65-4EBB-45e7-B440-6E39B2CDBF29}   (.NET 分类)
   HKLM\SOFTWARE\Classes\MechKit.Addin  +  \CLSID = {GUID}
   ```

3. 写入 SOLIDWORKS 插件清单与开机加载：

   ```
   HKLM\SOFTWARE\SolidWorks\AddIns\{GUID}          Title / Description
   HKLM + HKCU \SOFTWARE\SolidWorks\AddInsStartup\{GUID} = 1
   ```

4. 清掉开发期残留的 HKCU 注册，避免旧 CodeBase 指向 `bin\Release` 造成版本错乱。

安装完重启 SOLIDWORKS，就会出现：

- CommandManager 新增 **MechKit** 选项卡；
- 工具栏出现同名工具条（插件在加载时会调用 `SetToolbarVisibility`，装完即可见）；
- 「工具」菜单底部出现同样的命令；
- 「工具 → 插件」列表中已勾选 *Start Up*，之后随 SOLIDWORKS 自动加载。

> 如果工具条被手动关掉了，可从「视图 → 工具栏」重新勾选；想默认不弹出，
> 删除 `MechKitAddin.CreateCommandGroup()` 里的 `SetToolbarVisibility` 调用即可。

> **为什么必须要管理员权限？**
> SOLIDWORKS 只从 `HKEY_LOCAL_MACHINE\SOFTWARE\SolidWorks\AddIns\{GUID}` 读取插件列表
> （官方文档 *Distribute SOLIDWORKS Add-in* 的要求）。只写当前用户配置单元（HKCU）
> 时，SOLIDWORKS 启动时会把这个键删掉，插件不会出现在「工具 → 插件」里。
>
> 不带 `-Machine` 时脚本只做当前用户注册，用于开发期快速验证 COM 部分。
>
> **常见坑：`HKLM\SOFTWARE\Classes` 这个键本身可能不可写**（部分加固过的系统只允许
> 创建它的子键）。因此安装程序始终按完整路径 `CreateSubKey`，
> 不会先打开 `SOFTWARE\Classes` 再往下建——否则会出现"访问被拒绝"。

## 7. 常见问题

**插件没出现在「工具 → 插件」里**：确认用 `-Machine` 注册过，并重启 SOLIDWORKS。
可用 `tools\Test-Addin.ps1` 逐项检查注册表与 COM 激活。

**日志在哪**：`%LOCALAPPDATA%\MechKit\logs\MechKit-YYYYMMDD.log`。
每次连接会写 `[connect]`，卸载写 `[disconnect]`。

**想调整外购件识别范围**：编辑 `src\MechKit\Core\VendorKeywords.cs` 的
`Purchased` / `Standard` 关键词数组，重新构建即可。

**数量不对**：压缩的组件默认不计数；如需要，取消勾选「忽略压缩的组件」。
同一零件不同配置会分行统计。

## 8. 脚本编写约定

`tools\*.ps1` 与 `build.ps1` **必须保持纯 ASCII**：
Windows PowerShell 5.1 会用系统 ANSI 代码页读取无 BOM 的脚本，
脚本里直接写中文会破坏解析（中文放 JSON、C# 或本文档里）。
C# 文件的中文依赖 `<CodePage>65001</CodePage>` 编译选项。

外部图纸整体收录到 BOM，装配体不展开；保留完整图纸名称，材料、工艺等读取启用的自定义属性，并提供单独筛选和数量统计。

工程图的 MechKit 选项卡将“智能尺寸 → 公差助手 → 孔标注 → 销钉符号”放在同一个标注工具框中；智能尺寸、孔标注和销钉符号使用 SOLIDWORKS 原生命令与图标。

公差助手窗口顶部也提供“智能尺寸、公差助手、孔标注、销钉符号”四个按钮；公差助手返回公差预设页，其余按钮启动当前工程图的对应原生命令，窗口保持打开。

钣金工艺的加工件：有对应工程图时在工程图列显示实际工程图文件；没有工程图时显示“钣金”，表示不出图，也不按缺图标红。BOM CSV 使用同一规则。

日期后的第一段为“焊接”时（如 `20261011-焊接-机架`），按整体加工件收录 BOM，装配体不向下遍历；直接对该焊接装配体汇总时也只输出整体。


## BOM 关联资产

每个模型所在目录的 `assets` 保存对应配置的缩略图、标准件尺寸说明图和 STP/PDF 缓存。图片统一为 PNG；文件名包含模型名称、配置、用途和防重名标识。说明图保留原始分辨率，Excel 内按比例缩放。

在标准件行的“二维工程图”单元格按 Ctrl+V，可粘贴剪贴板图片或复制的单个图片文件，立即保存；再次粘贴替换该配置的说明图，双击该单元格打开图片。刷新、重启后关联仍保留，Excel 导出将说明图嵌入对应列。

缩略图按源文件内容校验；STP/PDF 同时检查源文件、递归引用、配置和相关全局导出设置。校验通过时复制缓存到原导出目录，否则重新导出。未保存修改或无法确认引用版本时不复用缓存。原输出目录及禁止覆盖规则继续生效。`.version` 文件用于资产完整性校验，请勿单独删除。移动项目时保留模型与 `assets` 的相对位置；重命名模型后需重新关联说明图。


## BOM 表格区域操作

鼠标拖动框选，Shift 扩选，Ctrl 选择不连续单元格，Ctrl+A 全选；Ctrl+C 复制选区（不带表头），Ctrl+V 从当前单元格按可见列顺序粘贴 Excel/WPS 多行多列文本，单个值可填入整个选区。Delete / Backspace 或右键菜单清空选中可编辑单元格，不删除行。单元格编辑中保留文本编辑快捷键。编辑时保留单元格选区，不再自动高亮整行。

数量、文件关联等只读列不改写；超出表格边界或同一文件同字段出现不同值时拒绝粘贴。同一文件各实例同步更新。批量修改的属性暂存在 BOM，点击“应用 BOM 修改”写回；名称修改通过原有重命名功能应用。设计备注仍立即保存到 assets。标准件二维工程图列的图片粘贴保持原功能。不提供合并单元格。

## 零部件设计备注

BOM 新增“设计备注”列，双击编辑，提交后立即保存。右侧“文档属性”页的当前文档信息下方显示同一条设计备注，包含完成复选框、创建时间和完成时间，可直接编辑并保存；离开输入框或切换文档时也会保存。只显示当前打开的零件或装配体，未保存的文档需先保存为外部文件。

首次保存非空备注时记录创建时间；勾选完成时记录完成时间，重复勾选不改写时间。取消完成会清空完成时间，修改已完成的备注会恢复为未完成并保留创建时间。清空备注会清空两个时间。BOM 与右侧栏同步，CSV / Excel 导出包含设计备注，关键词搜索也包含此列。

设计备注以 XML 保存在模型同目录的 `assets` 中，同一文件的不同配置共用一条，不修改模型中的原“备注”字段。移动项目时请保留 `assets`；模型重命名后目前需重新关联备注。示例：“淘宝加工-型材-型材总装”的设计备注为“要在和静音箱架对应位置打孔”。


### BOM 导入与自动生成的交叉校验

导入先按模型路径（表中有该列时）或三维名称/零件名称匹配，再用配置和位置核对。合并表中用中文分号连接的位置及名称必须全部匹配到同一模型文件、同一配置；不同文件或配置的重名不会自动合并。缺少部分位置或未保存模型时整行列为未匹配，不按序号猜测。

匹配后逐字段列出当前值、表格值、处理说明和更新复选框。支持更新选中字段或仅补空，空白单元格不清除旧值。文档级属性同步到同文件的所有预览实例（含筛选隐藏行），差异窗口显示实例数。数量只与匹配实例合计比较，不覆盖设计数量。

多个来源记录对同文件同字段提供不同值时只阻止该字段；该字段存在尚未保存的人工编辑或确认前发生变化时也保留当前值。其它有效字段仍可更新。备注、安装说明、采购文字和网址可正常回填；脚本及本地文件链接不能作为购买信息。取消差异窗口不会修改预览。导入后仍需“应用 BOM 修改”写入模型，未保存修改在重新生成前受提示保护。

重新生成前先检查未保存修改，选择保留时不清空预览。当前打开的是工程图而不是零件/装配体时，保留已有 BOM 并提示切换模型。BOM 导出期间禁止重复生成、导入和关闭窗口，避免导出过程被重入或使用已释放的窗口。

## 操作与卡顿诊断记录

加载 MechKit 后自动在 `%LOCALAPPDATA%\MechKit\logs` 创建 `Operations-日期-时间-进程号.log`。记录 MechKit 命令、BOM 主要操作的 BEGIN/END 和耗时、模型预览文件及配置，以及 SOLIDWORKS 命令编号、文档切换和文件打开关闭事件。END 表示调用返回，不代表业务成功；错误需结合 LOG 行判断。不会记录键盘输入或上传日志，文件路径和按钮名称会保存在本机。

后台线程写入日志，主界面心跳超过 10 秒未更新时写入 UI_STALL（包括未结束操作），恢复后写入 UI_RECOVERED。长时间计算或模态窗口也可能触发心跳告警，因此它是排查线索，不是死锁或根因证明。不能完整记录 SW 内部每一步操作。队列过载会记录 DROPPED 数量，正常会话结束后保留最近 30 份操作日志。

更新插件后需保存工作并重启 SOLIDWORKS 才会启用新记录器。再次卡住时记下大致时间，保留最新 Operations 日志和同日 MechKit 日志用于排查。

右侧 MechKit 任务面板新增 Log 选项卡，可切换当前会话的操作/卡顿日志与当天运行/错误日志。页面可见时每秒自动刷新，取消勾选可暂停，也可手动刷新或打开日志目录；后台读取并仅显示最近 64 KB，避免大日志拖慢界面。SW 主线程卡住时该面板也可能无法刷新，后台诊断仍写入磁盘。

BOM 的“位置”列支持右键菜单“打开上一级装配体”和“打开上二级装配体”，菜单显示目标名称。按当前行零件实例的真实父装配层级定位（包含组件容器），不按位置显示文字猜测文件；不存在或未保存为外部文件的层级禁用。筛选、排序后仍对应右键所在行，已打开的目标直接切换，操作写入诊断日志。更新后请重启 SW 并刷新 BOM。

右侧“工程图”区域新增“一键拷贝 p6061”：选择目标文件夹，将当前装配体（含下层组件）中可枚举的 p6061 零件及同目录同名 SLDDRW 工程图复制到目标目录；也支持当前单个 p6061 零件。按文件名第二段精确匹配，兼容横线和下划线、不区分大小写，不包含普通 6061。重复实例按路径去重，源文件同名冲突和目标已有文件跳过，不覆盖。目标目录生成复制报告，列出缺图、跳过及失败。复制磁盘已保存文件，不保存当前未保存修改、不改写工程图内部引用；需要独立迁移所有引用时应另用打包功能。

BOM 系统生成列现统一只读：序号、位置、三维名称、二维工程图、属性、零件名称/标准件名称、材料/型号、工艺/渠道、表面处理和数量，表头显示 🔒。这些列不能通过双击、键盘输入或粘贴修改，双击单元格复制其完整内容（空值不改剪贴板）。备注、安装说明、购买链接、设计备注保留手工编辑；文件命名通过命名工具维护。位置列右键打开父装配体功能保留。此规则替代此前在上述生成列内编辑或双击打开模型的行为。

BOM 不再展示独立“设计备注”列，原设计备注文件及右侧编辑区保留。“备注、安装说明、购买链接、未尽事宜”四列保留手工编辑，并按模型文件绑定保存到同目录 assets 内的“备注信息”XML。初次读取沿用命名解析及已有自定义属性；资产分别记录 generated 和 manual，手工值（含主动清空）优先，不被刷新覆盖。单元格编辑和粘贴直接保存资产，无需打开或保存 SW 模型；同一零件多个实例同步。旧 BOM 导入后点击应用时也同步备注资产。新字段参与 CSV/Excel 导出及合并导出。携带零件时请保留对应 assets 文件。

标准件的第三段及其后完整内容按首个英文字母或数字拆分：之前的名称显示在“零件名称/标准件名称”，从该字符起的所有内容显示在“材料/型号”，型号中的中文、数字、横线及其他后缀完整保留。例如双头外螺纹d6L25M5 → 双头外螺纹 / d6L25M5，右边ZNC334-3扭力2 → 右边 / ZNC334-3扭力2。纯中文名称型号为空；以字母或数字开头的整段归型号，名称为空。此规则优先于旧标准件名称/材料字段映射，适用于 BOM 显示及导出；加工件不变。

BOM 单击单元格后，该行保持浅蓝高亮及上下边线，鼠标移开或窗口失焦不清除，点击另一行后切换。高亮不扩大单元格选区，不改变复制、粘贴和编辑范围；排序与筛选按行数据保留高亮。

导出 XLSX 后自动关联 BOM 来源模型，工作簿隐藏“关联快照”列保存文件路径、配置和导出原值；请保留该列，使用表头筛选排序会连同关联列一起排序。修改 Excel 并保存后，点击 BOM 顶部“同步关联 Excel…”（预选上次关联文件），检查差异并确认。只回读相对导出原值发生变化的内容，按路径和配置匹配，同一文件实例同步；备注、安装说明、购买链接、未尽事宜直接保存资产。双边修改冲突及清空内容默认不勾选，必须人工逐项确认。名称、数量等系统生成列改动仅提示，需在模型/命名工具中处理后重新导出；无匹配、关联损坏、同文件值冲突或非法链接不写入。同步为主动操作，不后台监控 Excel；旧导出文件需重新导出才能关联。

“三维名称”恢复可编辑且移除锁标志：双击名称文字或按 F2 输入，提交后确认同步重命名。通过 SW RenameDocument 更新当前装配引用，同目录同名工程图先核验原引用，再另存新名并核验新引用，成功后清理旧图纸；目标重名、只读文件或引用校验失败会提示。生成字段仍保持只读。文件名不参与跨单元格批量填充；可在单元格编辑状态粘贴名称。保存过程中失败可能已发生部分修改，应保留当前 SW 文档按日志检查。未加载的其他装配体/异名工程图不在此同步范围。

BOM 获得焦点时按 Tab 会退到 SW 主窗口后面，再按可调回；长按只切换一次，松开后再按才再次切换。从 BOM 打开零件、装配体或工程图后自动让出绘图区，保留 BOM 状态。单元格编辑及模态弹窗中保留 Tab 原有行为，Alt+Tab 等组合键不受影响。

右侧‘文档属性’页在设计备注下方增加‘购买链接’和‘备注’输入框，绑定当前已保存的零件或装配体。点击‘保存并同步 BOM’、离开输入框或切换文档时保存到零部件的资产备注；已打开 BOM 的同文件行同步更新，BOM 中修改这两个字段也会更新面板。非法链接不写入，保存失败的输入保留为当前会话草稿。
