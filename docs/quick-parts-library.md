# 快捷零件库

右侧 MechKit 工作面板 → 快捷零件库。

- 初次使用创建空库：`文档\MechKit\零件库`，包含电控件、气动件、紧固件、其他。
- 直接放在零件库根目录的零件显示为“未分类”；可单独筛选。入库时选“未分类”即保存到根目录，不创建分类文件夹。
- “打开库”打开资源管理器；“添加零件进库”可多选本地 SLDPRT，再选择分类。
- 仅导入 SOLIDWORKS 2024 保存且无外部模型引用的独立零件。不提供或下载第三方模型。
- 分类与检索可同时使用；多个检索词用空格分隔，名称、型号和目录名均可匹配。手动修改目录后点击刷新。
- 打开并保存目标装配体，退出零部件编辑状态。按住列表中的零件，拖到当前装配体绘图区后松开。
- 松开时才复制到根装配体文件所在目录，随后插入副本。已有同名文件不覆盖，自动使用 `_1` 等后缀。Esc 或在绘图区外松开会取消。
- 放置点在经过装配体原点的视图平面上，按鼠标位置放置零件包围盒中心；不自动配合。透视视图下提示关闭透视后重试。
- 不自动保存装配体；插入后可移动、配合并自行保存。插入失败会尝试删除本次新建的副本。

验证：`powershell -NoProfile -File tools/Test-PartsLibrary.ps1` 检查版本判定、空库、检索、同名保护、失败回滚与窄侧栏布局。真实拖放与 SW 插入需在已打开的 SW 2024 中验收。
