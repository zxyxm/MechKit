# MechKit 功能核对（2026-10-14，0.35.2）

本清单对照当前源码、可见按钮、已有测试和近期运行日志。入口存在不等于所有模型都已验收；下面明确区分已实现与仍有缺口。

## 当前功能入口

| 区域 | 当前功能 | 状态与限制 |
|---|---|---|
| CommandManager | 打开工作面板、预览和导出 BOM | 主操作已移入右侧栏；旧命令回调仍可保留兼容 |

| 工程图 | 板件一键出图、车铣件出图、标注助手、激光切割 DXF | 四个按钮均存在 |
| 命名工具 | 下划线转短横线、撤回命名 | 按钮存在 |
| 日期 / 装配 / 组件 | 写入当天日期、写入装配、写入组件 | 已合并到一个板块，三个按钮保留 |
| 加工件 | 命名规则、材料及可配置名称快捷按钮 | 材料按钮省略“材料”文字，每列最多四行；有浅灰分隔线 |

| 快捷零件库 | 打开库、添加零件进库、刷新、分类、检索、Ctrl 拖入装配体 | 根目录为未分类，每个第一层文件夹为一个分类；松开时复制副本到装配体目录后插入；不自动配合或保存装配体 |
| 文档属性 | 当前文档信息、属性编辑、手动刷新统计 | 0.35.2 改为打开属性页时读取，数量统计只在手动刷新时执行 |

## 出图和标注的未完成项

1. **车铣件“完整全部尺寸”尚未达到。** 当前导入模型尺寸、原生孔标注，圆周件简化视图并使用第三角剖视位置。既有轴夹样例模型尺寸覆盖为 8/11；孔位、台阶、退刀槽等仍须复核，不能当作全自动完整加工图。
2. **板件不是任意几何的全尺寸自动出图。** 当前包含关联视图、包络、可识别孔规格、复用特征去重及近侧引线排布；槽型、密集标注及特殊入口仍有待复核项。SW 自动数量前缀保留。
3. **公差失效已定位并修复。** SW 2024 普通圆孔标注可能没有孔参数，旧代码跳过；现回退到原生关联直径尺寸公差。工程图副本测试回读 +0.03/0 mm 成功。
4. **新增设置销钉孔。** 选择工程图孔圆边或已有孔标注，生成/复用原生孔标注并设置 +0.03/0 mm；重复选择同一圆边不增加第二条标注。多参数孔没有明确主孔径时提示用预设选择，不自行给所有深度和直径加公差。
5. **激光 DXF 是最大平面导出。** 已验证 DXF 轮廓及单位；不是折弯钣金展开。仅支持已保存的独立单实体零件，已有同名 DXF 不覆盖。
6. **零件库尚未完成真实 Ctrl 拖放验收。** 文件检索、版本判定、复制与布局测试通过；拖放及放置位置需要用户实际操作确认。
7. **此前“所有 UI 全部截图”没有完整交付。** 当前源码有 8 个独立 Form，右侧面板有 3 个主选项卡；动态选择和编辑弹窗另计。

## 是合并移除还是意外丢失

- 独立“生成 BOM”按钮：按用户要求移除，入口统一为“预览和导出 BOM”。
- 独立“批量导出”按钮：并入 BOM 的 PDF / STP 导出。
- “公差助手”：更名“标注助手”，预设公差、前缀、后缀仍保留。
- “备件”默认大类：按用户要求移除，可通过其他大类管理添加需要的分类。
- “装配 / 组件”：曾移除，当前已恢复，和日期板块合并。
- 设置、导出配置、关于、刷新预览、属性批量写入：当前均有入口。
- 没有发现上述近期恢复的按钮再次从当前右侧栏代码中消失。

## 性能检查和验证范围

0.35.2 去掉了插件启动时的装配体深统计，并推迟隐藏文档属性页的 SW 读取。零件库拖动过程中缓存绘图区窗口句柄，避免每 40 ms 重复读取当前 SW 文档及视图。此次用户说明主要问题是孔标注无效，已用空孔参数的工程图副本复现并验证修复；未取得 CPU 采样，不能认定这些刷新改动解决所有卡顿。

BOM 遍历、工程图生成及批量导出仍在 SW 主线程执行，大装配体或复杂几何可能出现等待。后续应优先改善这几个长操作的取消、进度及耗时记录。

本次检查：构建、零件库、命令面板、窗口快捷键、BOM 工作区、标注助手预设和布局、普通尺寸公差实机测试、孔标注与销钉孔实机副本测试。历史完整 BOM 集成测试中 7 个旧备件分类断言未同步到新的可编辑分类规则，不应宣称完整集成测试全部通过。
